# 视频点播和直播

家里没有装iptv，因此想搞个免费的直播，了解到tvbox项目，这是个壳，还需要接入视频源才能观看

## tvbox历史

一开始是猫影视 TV (CatVodTV)，闭源的，然后因为合规问题，作者下架了这个软件，并把程序开源了CatVodTVOfficial，但是现在原始的开源仓库也404了

有很多基于CatVodTVOfficial二开的版本，目前主流的依然叫TVBox的是两个版本 

- 白壳 TVBox_q215613905 https://github.com/q215613905/TVBoxOS
- 黑壳 [TVBox_takagen99(没有任何release)](https://github.com/takagen99/Box)  [黑壳(更新很频繁)](https://github.com/j4Uq/TVBoxOSC?tab=readme-ov-file)

还有很多其他二开版本，有些开源有些闭源，更新频繁的有 okTV，影视仓(这两个是饭太硬的作者推荐的)

okTV的

其他下载哪个都差不多，变化不大

### 单个接口解析

一般是用爬虫去获取资源站的视频链接，很多资源站直接用的apple cms建的资源站，这个建站模板提供了接口直接返回数据库中的视频列表，也可以用爬虫程序二次整理这些列表。


```json5
{
  // 爬虫程序，
  "spider": "https://oss4liview.moji.com/thd_file/2026/03/01/d0120b0bceb0c421be3e4ce4afede46f.jpg;md5;daa01b2330c9adab32eb5fa2e93fd955",
  sites: [
    {
      "key": "玩偶",
      "name": "👽玩偶哥哥┃4K弹幕",
      "type": 3, // type为3时就是用爬虫去资源站获取视频列表
      "api": "csp_WoGGGuard",
      "timeout": 30,
      "searchable": 1,
      "quickSearch": 1,
      "changeable": 0,
      "ext": {
        "Cloud-drive": "tvfan/Cloud-drive.txt"
      }
    }
  ]
}

```

## 资源站
资源站返回的多数是网盘链接或者是切片网站的链接

tvbox有些网盘资源要登录才能看，有些不用，估计是资源站通过什么漏洞手段破解了vip。但是oktv里面给出的破解vip网盘的播放链接，浏览器直接访问又访问不了，可能是访问资源站还需要配置header啥的

而切片站的资源就是免费的了，比如著名的切片站点[量子资源网](https://lzizy.net/)

多数切片站点直接返回了.m3u8文件，最新版的chrome已经可以直接打开了

网盘一般就返回的视频原链

可以尝试用苹果CMS自建视频网站，然后具体的视频链接从量子资源网采集，再然后提供接口或者写tvbox的spider把自建网站的资源提供给tvbox播放

盗版真是一条龙啊

## 直播源收集

小孩要看动漫，但是游魂收集的直播源中只有cctv14，饭太硬接口源中包含的[直播源Kimentanm](https://raw.githubusercontent.com/Kimentanm/aptv/master/m3u/iptv.m3u)也只有cctv14

因此我想收集下少儿频道直播源，自己做成配置文件，上传到github，维护一个少儿频道直播源

国内常用少儿频道：
- cctv14
- 卡酷少儿卫视（北京广播电视台）
- 金鹰卡通卫视（湖南广播电视台）
- 嘉佳卡通卫视（广东广播电视台）
- 优漫卡通卫视（江苏省广播电视总台）
- 炫动卡通卫视（上海广播电视台）


目录名称,#genre#  // 按这种格式即可
```txt
少儿频道,#genre#
CCTV14,http://101.35.240.114:88/live.php?id=CCTV14
浙江少儿,http://ali-xwl.cztv.com/live/channel081080Plxw.m3u8
浙江少儿,http://ali-xwl.cztv.com/live/channel08720Plxw.m3u8
南京少儿,http://nklive.nbs.cn/hls/e0981f3f-1a20-4a59-b8d1-17feb83a4610/index.m3u8
```

保存为txt，放到手机上，直播源那选本地文件导入即可
